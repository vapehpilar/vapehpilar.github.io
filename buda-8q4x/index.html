Hola, Buda

Este panel es privado. Ingresá tu clave de GoatCounter para ver las analíticas.

¿Dónde saco la clave?
  1. Entrá a goatcounter.com con tu cuenta.
  2. Andá a Settings → API (arriba a la derecha, tu usuario).
  3. Tocá New API key, marcá solo Read statistics y guardá.
  4. Copiá la clave y pegala acá.

La clave queda guardada solo en tu navegador. Nunca se sube a la página ni a GitHub.
